A virtual account in NDAPI is a unique bank account number provisioned on behalf of one of your customers, backed by a real bank in a supported market. When your customer shares their virtual account number with a payer, any funds sent to that number are automatically detected, reconciled, and surfaced to you via webhooks and transaction records — with no manual intervention required on your part. This makes virtual accounts the foundation for building reliable, scalable payment collection flows across Africa.

## How Virtual Accounts Work

When you create a virtual account, NDAPI assigns a real bank account number from one of our banking partners in the relevant market. That account number is permanently associated with the customer reference you provide. Every inbound payment — regardless of the sender's bank or transfer method — triggers two things:

1. A `virtual_account.credited` webhook event is dispatched to your registered endpoint.
2. A `credit` transaction is recorded against the virtual account in your NDAPI ledger.

This means you always have both a real-time notification and a durable audit trail for every payment your customers receive.

## Virtual Account Lifecycle

A virtual account moves through a defined set of states from the moment it is provisioned to the moment it is decommissioned.

| State | Description |
|---|---|
| `created` | The account has been provisioned and account number assigned, but is not yet active. |
| `active` | The account is live and ready to receive inbound payments. |
| `suspended` | The account is temporarily disabled. Inbound payments are rejected. |
| `closed` | The account is permanently deactivated. It cannot be reopened. |

<Note>
  State transitions are one-directional for `closed` accounts. Once a virtual account is closed, it cannot be moved back to `active` or `suspended`. If you need to temporarily pause a customer's ability to receive payments, use `suspended` instead.
</Note>

## Virtual Account Object

The following fields are returned whenever you create, retrieve, or list virtual accounts through the NDAPI API.

| Field | Type | Description |
|---|---|---|
| `id` | string | Unique identifier for the virtual account, prefixed with `va_`. |
| `account_number` | string | The bank account number assigned to this virtual account. |
| `account_name` | string | The account holder name registered with the bank. |
| `bank_name` | string | Human-readable name of the issuing bank. |
| `bank_code` | string | Numeric or alphanumeric code identifying the issuing bank. |
| `currency` | string | ISO 4217 currency code for the account (e.g. `NGN`, `KES`). |
| `status` | string | Current lifecycle state: `active`, `suspended`, or `closed`. |
| `customer_name` | string | Full name of the customer this account belongs to. |
| `customer_email` | string | Email address of the customer this account belongs to. |
| `reference` | string | Your own internal reference, passed at creation time. Used for reconciliation on your side. |
| `created_at` | string | ISO 8601 timestamp recording when the account was provisioned. |

A complete virtual account object looks like this:

```json
{
  "id": "va_01HXYZ456ABC",
  "account_number": "0123456789",
  "account_name": "NDAPI / Amara Nwosu",
  "bank_name": "First Bank of Nigeria",
  "bank_code": "011",
  "currency": "NGN",
  "status": "active",
  "customer_name": "Amara Nwosu",
  "customer_email": "amara.nwosu@example.com",
  "reference": "CUST-0042",
  "created_at": "2024-01-15T08:00:00Z"
}
```

## Supported Currencies

Virtual accounts can be provisioned in the following currencies, each backed by a local banking partner in the corresponding market:

## Per-Account Limits

<Note>
  As an operator, you can configure spending and collection limits on a per-virtual-account basis. This lets you enforce compliance thresholds, tier your product offerings, or cap exposure for specific customer segments. Limits can be set at creation time via the `limits` object or updated at any point while the account is `active` or `suspended`. Contact your NDAPI account manager or visit the [NDAPI Dashboard](https://dashboard.ndapi.io) to configure default limits for all newly created accounts under your operator profile.
</Note>
