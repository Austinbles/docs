Virtual accounts let you assign a unique bank account number to each of your customers, enabling you to receive and reconcile inbound payments automatically. The endpoints below cover creating a virtual account for a customer, fetching a single account by ID, and paginating through all virtual accounts on your integration.

---

## POST /virtual-accounts

Create a new virtual account for a customer. Each request must carry a unique `reference` value, which NDAPI uses as an idempotency key — submitting the same `reference` twice returns the original response without creating a duplicate account.

### Request Body

<ParamField body="currency" type="string" required>
  ISO 4217 currency code for the virtual account. Supported values: `NGN`, `GHS`, `KES`, `ZAR`.
</ParamField>

<ParamField body="customer_name" type="string" required>
  Full legal name of the account holder. This is printed on the virtual account and used for beneficiary matching by receiving banks.
</ParamField>

<ParamField body="customer_email" type="string" required>
  Email address of the account holder. Must be a valid email format.
</ParamField>

<ParamField body="reference" type="string" required>
  A unique string you generate to identify this request. Re-submitting the same `reference` returns the original virtual account rather than creating a new one. Maximum 100 characters.
</ParamField>

<ParamField body="metadata" type="object">
  Arbitrary key-value pairs you want to attach to the virtual account. Values must be strings. Returned as-is in all subsequent reads.
</ParamField>

### Response Fields

<ResponseField name="id" type="string">
  NDAPI-assigned unique identifier for the virtual account (e.g. `va_01HX…`).
</ResponseField>

<ResponseField name="account_number" type="string">
  The bank account number assigned to this virtual account.
</ResponseField>

<ResponseField name="account_name" type="string">
  The name under which the account is registered at the bank. Typically mirrors `customer_name`.
</ResponseField>

<ResponseField name="bank_name" type="string">
  Human-readable name of the bank that issued the virtual account number.
</ResponseField>

<ResponseField name="bank_code" type="string">
  Numeric or alphanumeric code that identifies the issuing bank within the local clearing network.
</ResponseField>

<ResponseField name="currency" type="string">
  ISO 4217 currency code associated with this account.
</ResponseField>

<ResponseField name="status" type="string">
  Current state of the virtual account. One of `active`, `inactive`, or `frozen`.
</ResponseField>

<ResponseField name="customer_name" type="string">
  Full name of the account holder as provided in the request.
</ResponseField>

<ResponseField name="customer_email" type="string">
  Email address of the account holder as provided in the request.
</ResponseField>

<ResponseField name="reference" type="string">
  The unique reference you supplied when creating the account.
</ResponseField>

<ResponseField name="metadata" type="object">
  Arbitrary key-value pairs you attached to the virtual account at creation time. All values are strings. Returned as-is in all subsequent reads.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp of when the virtual account was created.
</ResponseField>

### Code Examples

<CodeGroup>

```bash curl
curl --request POST \
  --url https://api.ndapi.io/v1/virtual-accounts \
  --header 'Authorization: Bearer <API_KEY>' \
  --header 'Content-Type: application/json' \
  --data '{
    "currency": "NGN",
    "customer_name": "Amara Okonkwo",
    "customer_email": "amara.okonkwo@example.com",
    "reference": "cust-va-00123",
    "metadata": {
      "internal_user_id": "usr_9821",
      "plan": "premium"
    }
  }'
```

```javascript Node.js
const response = await fetch('https://api.ndapi.io/v1/virtual-accounts', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer <API_KEY>',
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    currency: 'NGN',
    customer_name: 'Amara Okonkwo',
    customer_email: 'amara.okonkwo@example.com',
    reference: 'cust-va-00123',
    metadata: {
      internal_user_id: 'usr_9821',
      plan: 'premium',
    },
  }),
});

const data = await response.json();
console.log(data);
```

</CodeGroup>

## GET /virtual-accounts/:id

Retrieve full details of a single virtual account using its NDAPI-assigned ID.

### Path Parameters

<ParamField path="id" type="string" required>
  The unique ID of the virtual account (e.g. `va_01HX4KBZQR9MNDP7T2WGFC`).
</ParamField>

### Response Fields

The response object contains the same fields as the [POST /virtual-accounts](#post-virtual-accounts) response. See the field descriptions above.

### Code Examples

<CodeGroup>

```bash curl
curl --request GET \
  --url https://api.ndapi.io/v1/virtual-accounts/va_01HX4KBZQR9MNDP7T2WGFC \
  --header 'Authorization: Bearer <API_KEY>'
```

```javascript Node.js
const id = 'va_01HX4KBZQR9MNDP7T2WGFC';

const response = await fetch(`https://api.ndapi.io/v1/virtual-accounts/${id}`, {
  method: 'GET',
  headers: {
    'Authorization': 'Bearer <API_KEY>',
  },
});

const data = await response.json();
console.log(data);
```

</CodeGroup>

## GET /virtual-accounts

Return a paginated list of all virtual accounts on your integration. Use the `currency` and `status` query parameters to narrow results.

### Query Parameters

<ParamField query="page" type="integer">
  Page number to retrieve. Defaults to `1`.
</ParamField>

<ParamField query="per_page" type="integer">
  Number of records per page. Defaults to `20`. Maximum is `100`.
</ParamField>

<ParamField query="currency" type="string">
  Filter results to a specific currency. One of `NGN`, `GHS`, `KES`, `ZAR`.
</ParamField>

<ParamField query="status" type="string">
  Filter by account status. One of `active`, `inactive`, or `frozen`.
</ParamField>

### Code Examples

<CodeGroup>

```bash curl
curl --request GET \
  --url 'https://api.ndapi.io/v1/virtual-accounts?page=1&per_page=20&currency=NGN&status=active' \
  --header 'Authorization: Bearer <API_KEY>'
```

```javascript Node.js
const params = new URLSearchParams({
  page: '1',
  per_page: '20',
  currency: 'NGN',
  status: 'active',
});

const response = await fetch(
  `https://api.ndapi.io/v1/virtual-accounts?${params}`,
  {
    method: 'GET',
    headers: {
      'Authorization': 'Bearer <API_KEY>',
    },
  }
);

const data = await response.json();
console.log(data);
```

</CodeGroup>
