## Create a virtual account

`POST /virtual-accounts`

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `account_name` | string | Yes | Your customer's name. Shown as `{your business name}/{account_name}`. |
| `merchant_tx_ref` | string | Yes | Your own order or customer ID. Returned as `reference` in webhooks. Sending the same value again returns the existing account. |
| `expected_amount` | number | No | Informational. Payments of any amount are accepted and credited as received. |
| `expires_at` | string | No | ISO 8601 expiry. Omit for a permanent account. |

<CodeGroup>
```bash cURL
curl -X POST https://api.nolubz.com/v1/virtual-accounts \
  -H "x-api-key: NDAPI-LIVE-your_live_key" \
  -H "Content-Type: application/json" \
  -d '{
    "account_name": "John Doe",
    "merchant_tx_ref": "ORDER-2026-001",
    "expected_amount": 50000,
    "expires_at": "2026-12-31T23:59:59Z"
  }'
```

```python Python
resp = requests.post(
    "https://api.nolubz.com/v1/virtual-accounts",
    headers={"x-api-key": os.environ["NDAPI_API_KEY"]},
    json={
        "account_name": "John Doe",
        "merchant_tx_ref": "ORDER-2026-001",
        "expected_amount": 50000,
        "expires_at": "2026-12-31T23:59:59Z",
    },
)
```
</CodeGroup>

```json Response
{
  "success": true,
  "data": {
    "account_number": "9646780657",
    "account_name": "YourBusiness/John Doe",
    "bank": "<bank name>",
    "reference": "ORDER-2026-001",
    "account_ref": "ndapi_...",
    "expected_amount": 50000,
    "currency": "<currency_code>",
    "expires_at": "2026-12-31T23:59:59Z",
    "status": "active"
  }
}
```

## Verify a bank account

`POST /virtual-accounts/verify`

Look up the account name before sending a transfer.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `account_number` | string | Yes | Recipient account number |
| `bank_code` | string | Yes | Recipient bank code. See [bank codes](/api-reference/transfers#bank-codes). |

<CodeGroup>
```bash cURL
curl -X POST https://api.nolubz.com/v1/virtual-accounts/verify \
  -H "x-api-key: NDAPI-LIVE-your_live_key" \
  -H "Content-Type: application/json" \
  -d '{ "account_number": "0123456789", "bank_code": "BANK_CODE" }'
```

```javascript Node.js
const res = await fetch("https://api.nolubz.com/v1/virtual-accounts/verify", {
  method: "POST",
  headers: { "x-api-key": process.env.NDAPI_API_KEY, "Content-Type": "application/json" },
  body: JSON.stringify({ account_number: "0123456789", bank_code: "BANK_CODE" }),
});
const { data } = await res.json();
console.log(data.account_name);
```

```python Python
resp = requests.post(
    "https://api.nolubz.com/v1/virtual-accounts/verify",
    headers={"x-api-key": os.environ["NDAPI_API_KEY"]},
    json={"account_number": "0123456789", "bank_code": "BANK_CODE"},
)
print(resp.json()["data"]["account_name"])
```

```php PHP
<?php
$ch = curl_init('https://api.nolubz.com/v1/virtual-accounts/verify');
curl_setopt_array($ch, [
  CURLOPT_POST => true,
  CURLOPT_RETURNTRANSFER => true,
  CURLOPT_HTTPHEADER => ['x-api-key: ' . getenv('NDAPI_API_KEY'), 'Content-Type: application/json'],
  CURLOPT_POSTFIELDS => json_encode(['account_number' => '0123456789', 'bank_code' => 'BANK_CODE']),
]);
$name = json_decode(curl_exec($ch), true)['data']['account_name'];
```
</CodeGroup>

```json Response
{
  "success": true,
  "data": {
    "account_name": "JANE SMITH",
    "account_number": "0123456789",
    "bank_code": "BANK_CODE"
  }
}
```

If the account can't be found you get HTTP `404` with `"Account not found. Check the account number and bank code."`
