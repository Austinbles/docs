## Base URL

```
https://api.nolubz.com/v1
```

Test and live requests use the same base URL. Your API key prefix (`NDAPI-TEST-` or `NDAPI-LIVE-`) selects the mode. See [Authentication](/api-reference/authentication).

## Endpoints

| Method | Endpoint | Purpose |
| --- | --- | --- |
| `POST` | [`/virtual-accounts`](/api-reference/virtual-accounts) | Create a virtual account |
| `POST` | [`/virtual-accounts/verify`](/api-reference/virtual-accounts#verify-a-bank-account) | Verify a bank account name |
| `POST` | [`/transfers`](/api-reference/transfers) | Send a bank transfer |
| `GET` | [`/banks`](/api-reference/transfers#bank-codes) | List supported banks and their codes |
| `GET` | [`/transactions`](/api-reference/transactions) | List or look up transactions |
| `GET` | [`/balance`](/api-reference/balance) | Get your balance |
| `POST` | [`/simulate`](/api-reference/webhooks) | Fire a test webhook (test mode only) |

## Requests

Send JSON bodies with `Content-Type: application/json`. Amounts are numbers in the major currency unit. Timestamps are ISO 8601 in UTC.

## Responses

Successful responses look like this:

```json
{
  "success": true,
  "data": { }
}
```

Errors return an `error` message and a matching HTTP status. See [Errors](/api-reference/errors).

## Fair use

NDAPI is built for high volumes. Keep requests to what your integration needs: cache the bank list, rely on webhooks instead of polling, and look up single transactions by reference. If you expect large bursts (for example, bulk payouts), tell us in advance through [operator support](https://ndapi.nolubz.com/support) so we can plan capacity with you.
