---
title: "Authentication"
description: "API key header, key prefixes and authentication errors."
---

Send your API key in the `x-api-key` header on every request.

```bash
curl https://api.nolubz.com/v1/balance \
  -H "x-api-key: NDAPI-LIVE-your_live_key"
```

| Key prefix | Mode |
| --- | --- |
| `NDAPI-TEST-` | Test: no real money moves |
| `NDAPI-LIVE-` | Live: real payments |

Requests are only accepted from IP addresses registered for your account.

| HTTP status | Error | Cause |
| --- | --- | --- |
| 401 | Missing API key | No key in the `x-api-key` header |
| 401 | Invalid API key format | Key doesn't start with `NDAPI-TEST-` or `NDAPI-LIVE-` |
| 401 | Invalid API key | Unknown key |
| 401 | Operator account suspended | Contact ndapi.admin@nolubz.com |
| 403 | IP address not permitted | Request came from an unregistered IP address |

Full details: [Authentication guide](/authentication).
