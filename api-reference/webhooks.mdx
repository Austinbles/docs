Webhooks let NDAPI push real-time event notifications to your server the moment something meaningful happens — a virtual account is credited, a transfer succeeds, or a transfer fails. Instead of polling our API repeatedly, you register an HTTPS endpoint and we `POST` a signed JSON payload to it. The endpoints below let you create, inspect, list, and delete webhook registrations on your integration.

---

## POST /webhooks

Register a new webhook endpoint to begin receiving event notifications. You can subscribe to specific event types or use the wildcard `["*"]` to receive all events. NDAPI signs every delivery with an `X-NDAPI-Signature` header so you can verify authenticity on your server.

### Request Body

<ParamField body="url" type="string" required>
  The fully-qualified HTTPS URL of your webhook receiver (e.g. `https://yourapp.com/webhooks/ndapi`). HTTP URLs are not accepted.
</ParamField>

<ParamField body="events" type="array" required>
  An array of event type strings you want to subscribe to. Example values:
  - `virtual_account.credited` — a virtual account received an inbound payment
  - `transfer.success` — an outbound transfer completed successfully
  - `transfer.failed` — an outbound transfer was declined or failed

  Pass `["*"]` to subscribe to every event type now and in the future.
</ParamField>

<ParamField body="secret" type="string">
  A custom signing secret used to compute the `X-NDAPI-Signature` HMAC on each delivery. If you omit this, NDAPI auto-generates a cryptographically random secret and returns it in the response. Store it securely — it is only shown once.
</ParamField>

### Response Fields

<ResponseField name="id" type="string">
  NDAPI-assigned unique identifier for the webhook registration (e.g. `wh_01JA…`).
</ResponseField>

<ResponseField name="url" type="string">
  The HTTPS URL that will receive event payloads.
</ResponseField>

<ResponseField name="events" type="array">
  The list of event types this webhook is subscribed to, exactly as registered.
</ResponseField>

<ResponseField name="status" type="string">
  Current state of the webhook endpoint. One of `active` or `disabled`. Endpoints that repeatedly return non-2xx responses are automatically disabled.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp of when the webhook was registered.
</ResponseField>

### Code Examples

<CodeGroup>

```bash curl
curl --request POST \
  --url https://api.ndapi.io/v1/webhooks \
  --header 'Authorization: Bearer <API_KEY>' \
  --header 'Content-Type: application/json' \
  --data '{
    "url": "https://yourapp.com/webhooks/ndapi",
    "events": ["virtual_account.credited", "transfer.success", "transfer.failed"],
    "secret": "my_custom_signing_secret"
  }'
```

```javascript Node.js
const response = await fetch('https://api.ndapi.io/v1/webhooks', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer <API_KEY>',
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    url: 'https://yourapp.com/webhooks/ndapi',
    events: ['virtual_account.credited', 'transfer.success', 'transfer.failed'],
    secret: 'my_custom_signing_secret',
  }),
});

const data = await response.json();
console.log(data);
```

</CodeGroup>

**Example response**

```json
{
  "status": "success",
  "data": {
    "id": "wh_01JA7KBZQRMNDP4T2WGFC9X",
    "url": "https://yourapp.com/webhooks/ndapi",
    "events": [
      "virtual_account.credited",
      "transfer.success",
      "transfer.failed"
    ],
    "status": "active",
    "created_at": "2024-06-15T08:30:00Z"
  }
}
```

## GET /webhooks

List all webhook endpoints registered on your integration, with optional pagination.

### Query Parameters

<ParamField query="page" type="integer">
  Page number to retrieve. Defaults to `1`.
</ParamField>

<ParamField query="per_page" type="integer">
  Number of records per page. Defaults to `20`. Maximum is `100`.
</ParamField>

### Response Fields

Each item in the `data` array contains the same fields as the [POST /webhooks](#post-webhooks) response. See the field descriptions above.

<ResponseField name="data" type="array">
  Array of webhook registration objects. Each object contains `id`, `url`, `events`, `status`, and `created_at`.
</ResponseField>

<ResponseField name="meta" type="object">
  Pagination metadata.

  <Expandable title="meta fields">
    <ResponseField name="page" type="integer">
      The current page number returned.
    </ResponseField>
    <ResponseField name="per_page" type="integer">
      Number of records per page.
    </ResponseField>
    <ResponseField name="total" type="integer">
      Total number of webhook registrations across all pages.
    </ResponseField>
    <ResponseField name="total_pages" type="integer">
      Total number of pages available.
    </ResponseField>
  </Expandable>
</ResponseField>

### Code Examples

<CodeGroup>

```bash curl
curl --request GET \
  --url 'https://api.ndapi.io/v1/webhooks?page=1&per_page=20' \
  --header 'Authorization: Bearer <API_KEY>'
```

```javascript Node.js
const params = new URLSearchParams({ page: '1', per_page: '20' });

const response = await fetch(
  `https://api.ndapi.io/v1/webhooks?${params}`,
  {
    method: 'GET',
    headers: {
      'Authorization': 'Bearer <API_KEY>',
    },
  }
);

const data = await response.json();
console.log(data);
```

</CodeGroup>

**Example response**

```json
{
  "status": "success",
  "data": [
    {
      "id": "wh_01JA7KBZQRMNDP4T2WGFC9X",
      "url": "https://yourapp.com/webhooks/ndapi",
      "events": [
        "virtual_account.credited",
        "transfer.success",
        "transfer.failed"
      ],
      "status": "active",
      "created_at": "2024-06-15T08:30:00Z"
    }
  ],
  "meta": {
    "page": 1,
    "per_page": 20,
    "total": 1,
    "total_pages": 1
  }
}
```

## GET /webhooks/:id

Retrieve the registration details of a single webhook endpoint by its NDAPI ID.

### Path Parameters

<ParamField path="id" type="string" required>
  The unique ID of the webhook registration (e.g. `wh_01JA7KBZQRMNDP4T2WGFC9X`).
</ParamField>

### Response Fields

The response object contains the same fields as the [POST /webhooks](#post-webhooks) response. See the field descriptions above.

### Code Examples

<CodeGroup>

```bash curl

  --url https://api.ndapi.io/v1/webhooks/wh_01JA7KBZQRMNDP4T2WGFC9X \
```

## DELETE /webhooks/:id

Permanently remove a webhook endpoint. NDAPI will stop delivering events to the registered URL immediately after deletion. A successful request returns `204 No Content` with an empty response body.

### Path Parameters

<ParamField path="id" type="string" required>
  The unique ID of the webhook registration to delete (e.g. `wh_01JA7KBZQRMNDP4T2WGFC9X`).
</ParamField>

### Code Examples

<CodeGroup>

```bash curl
curl --request DELETE \
  --url https://api.ndapi.io/v1/webhooks/wh_01JA7KBZQRMNDP4T2WGFC9X \
  --header 'Authorization: Bearer <API_KEY>'
```

```javascript Node.js
const id = 'wh_01JA7KBZQRMNDP4T2WGFC9X';

const response = await fetch(`https://api.ndapi.io/v1/webhooks/${id}`, {
  method: 'DELETE',
  headers: {
    'Authorization': 'Bearer <API_KEY>',
  },
});

// 204 No Content — no response body
console.log(response.status); // 204
```

</CodeGroup>

<Warning>
  Deleting a webhook endpoint is irreversible. Once removed, the registration cannot be recovered and NDAPI will cease all future deliveries to that URL. Any events that were already queued or in-flight at the moment of deletion may still be delivered — ensure your server handles these gracefully before removing an endpoint.
</Warning>
