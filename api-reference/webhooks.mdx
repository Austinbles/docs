`POST /simulate`

Send any webhook event to your endpoint without a real transaction. Works only with `NDAPI-TEST-` keys.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `event` | string | Yes | Event to fire (see below) |
| `webhook_url` | string | No | Overrides your configured webhook URL |
| `params` | object | No | Customise the payload: `reference`, `amount`, `account_number` |

Available events: `payment.received`, `payment.failed`, `transfer.success`, `transfer.pending`, `transfer.failed`, `balance.low`.

```bash
curl -X POST https://api.nolubz.com/v1/simulate \
  -H "x-api-key: NDAPI-TEST-your_test_key" \
  -H "Content-Type: application/json" \
  -d '{
    "event": "payment.received",
    "webhook_url": "https://your-server.com/ndapi/webhook",
    "params": { "reference": "TEST-ORDER-001", "amount": 10000 }
  }'
```

```json Response
{
  "success": true,
  "mode": "test",
  "event": "payment.received",
  "webhook_url": "https://your-server.com/ndapi/webhook",
  "payload": { },
  "signature_algorithm": "Base64(HMAC-SHA256(webhook_secret, raw_request_body))",
  "webhook_response": { "status": "delivered", "http_status": 200, "body": "ok" }
}
```

- `payload` is the exact body sent to your endpoint.
- Simulated webhooks include `"mode": "test"` inside `data`.
- Simulated events are recorded as transactions. Confirm with `GET /transactions?reference=...`.

Webhook endpoints are configured at onboarding or in your Operator Portal, not through the API.

See [Testing your integration](/guides/testing) for examples in Node.js, Python and PHP, every simulatable event, and the scenarios to test before going live.
