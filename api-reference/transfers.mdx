## Send a transfer

`POST /transfers`

<Warning>
  The recipient receives the full `amount`. Your balance is debited `total_deducted` (`amount + fee + provider_fee`) as soon as the transfer is accepted. Always [verify the account name](/api-reference/virtual-accounts#verify-a-bank-account) first.
</Warning>

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `amount` | number | Yes | Amount the recipient receives, in full. |
| `bank_code` | string | Yes | Recipient bank code from [`GET /banks`](#bank-codes). Examples on this page use `BANK_CODE` as a placeholder. |
| `account_number` | string | Yes | Recipient account number |
| `account_name` | string | Yes | Recipient account name, from Verify Account |
| `reference` | string | Yes | Your unique reference. Used for idempotency. |
| `narration` | string | No | Description shown to the recipient |
| `bank_name` | string | No | Recipient bank name, for your records |

<CodeGroup>
```bash cURL
curl -X POST https://api.nolubz.com/v1/transfers \
  -H "x-api-key: NDAPI-LIVE-your_live_key" \
  -H "Content-Type: application/json" \
  -d '{
    "amount": 50000,
    "bank_code": "BANK_CODE",
    "account_number": "0123456789",
    "account_name": "JANE SMITH",
    "reference": "PAYOUT-2026-001",
    "narration": "Payment for order #1234"
  }'
```

```javascript Node.js
const res = await fetch("https://api.nolubz.com/v1/transfers", {
  method: "POST",
  headers: {
    "x-api-key": process.env.NDAPI_API_KEY,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    amount: 50000,
    bank_code: "BANK_CODE",
    account_number: "0123456789",
    account_name: "JANE SMITH",
    reference: "PAYOUT-2026-001",
    narration: "Payment for order #1234",
  }),
});
const { data } = await res.json();
```
</CodeGroup>

```json Response
{
  "success": true,
  "mode": "live",
  "data": {
    "reference": "PAYOUT-2026-001",
    "amount": 50000,
    "fee": "<as per your agreement>",
    "provider_fee": "<bank transfer charge>",
    "net_amount": 50000,
    "total_deducted": "<amount + fee + provider_fee>",
    "currency": "<currency_code>",
    "status": "completed",
    "transaction_id": 42,
    "provider_ref": "TRF-..."
  }
}
```

| Status | Meaning |
| --- | --- |
| `completed` | Funds delivered |
| `pending` | Processing; watch for `transfer.success` or `transfer.failed` |
| `failed` | Failed; balance restored automatically |

## Bank codes

Get the full, current list of supported banks and their codes from the API. It covers commercial, merchant, microfinance and fintech banks, and always matches the codes `POST /transfers` accepts.

`GET /banks`

| Parameter | Required | Description |
| --- | --- | --- |
| `search` | No | Filter by bank name, for example `opay` |

```bash
curl "https://api.nolubz.com/v1/banks?search=bank" \
  -H "x-api-key: NDAPI-LIVE-your_live_key"
```

```json Response
{
  "success": true,
  "data": {
    "country": "NG",
    "count": 2,
    "banks": [
      { "code": "<bank_code>", "name": "Example Commercial Bank" },
      { "code": "<bank_code>", "name": "Example Microfinance Bank" }
    ]
  }
}
```

<Tip>
  Load the list once and cache it in your app, for example to fill a bank picker. Don't hard-code bank codes; always use the codes from this endpoint.
</Tip>

Can't find a bank? Contact [operator support](https://ndapi.nolubz.com/support).
