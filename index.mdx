Welcome to NDAPI — the payment infrastructure layer built for African fintech operators. Whether you're running a neobank, a lending platform, or a payments product, NDAPI gives you a single, consistent REST API to create virtual accounts, move money, query balances, track transactions, and react to real-time webhook events. You can go from zero to your first live transaction in under five minutes.
