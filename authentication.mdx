title: "Authentication"
description: "Authenticate every request with your API key in the x-api-key header."
---

Every request to NDAPI must include your API key in the `x-api-key` header.

```bash
x-api-key: NDAPI-TEST-your_test_key
```

## Your credentials

You receive these at onboarding:

| Credential | Format | Used for |
| --- | --- | --- |
| Test API key | `NDAPI-TEST-...` | Development and testing |
| Live API key | `NDAPI-LIVE-...` | Production (issued at go-live) |
| Webhook secret | `NDAPI-WH-...` | Verifying webhook signatures |

## Test and live mode

Test and live use the same base URL, `https://api.nolubz.com/v1`. The key prefix decides the mode.

| Key prefix | Mode | Behaviour |
| --- | --- | --- |
| `NDAPI-TEST-` | Test | No real money moves. Realistic mock responses. |
| `NDAPI-LIVE-` | Live | Real payments and real bank transfers. |

What works in test mode:

| Feature | Test mode |
| --- | --- |
| Create virtual account | Returns a mock account number |
| Check balance | Returns your real test ledger balance |
| Initiate transfer | Returns a mock success; no real transfer |
| Verify account | Real account name lookup |
| Webhooks | Fire them on demand with the [simulator](/api-reference/webhooks) |
| Real deposits | Not supported |

## IP whitelisting

API requests are accepted only from IP addresses registered for your account. Send your server's public IP addresses to [ndapi.admin@nolubz.com](mailto:ndapi.admin@nolubz.com) before you start testing. Requests from other addresses are rejected.

<Warning>
  Never put API keys in client-side code, mobile apps or public repositories. Call NDAPI only from your backend, and keep keys in environment variables.
</Warning>

## Authentication errors

| HTTP status | Error | Cause |
| --- | --- | --- |
| 401 | Missing API key | No key was sent in the `x-api-key` header. |
| 401 | Invalid API key format | The key doesn't start with `NDAPI-TEST-` or `NDAPI-LIVE-`. |
| 401 | Invalid API key | The key is not recognised. |
| 401 | Operator account suspended | Your account is suspended. Contact ndapi.admin@nolubz.com. |
| 403 | IP address not permitted | The request came from an IP address not registered for your account. |
