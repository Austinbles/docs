## Before you start

You need your test API key and webhook secret (provided at onboarding), and a server whose IP address is registered with us. See [Authentication](/authentication).

## Step 1: Create a virtual account

<CodeGroup>
```bash cURL
curl -X POST https://api.nolubz.com/v1/virtual-accounts \
  -H "x-api-key: NDAPI-TEST-your_test_key" \
  -H "Content-Type: application/json" \
  -d '{
    "account_name": "John Doe",
    "merchant_tx_ref": "ORDER-2026-001"
  }'
```

```javascript Node.js
const res = await fetch("https://api.nolubz.com/v1/virtual-accounts", {
  method: "POST",
  headers: {
    "x-api-key": process.env.NDAPI_API_KEY,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    account_name: "John Doe",
    merchant_tx_ref: "ORDER-2026-001",
  }),
});
const { data } = await res.json();
console.log(data.account_number); // share this with your customer
```

```python Python
import os, requests

resp = requests.post(
    "https://api.nolubz.com/v1/virtual-accounts",
    headers={"x-api-key": os.environ["NDAPI_API_KEY"]},
    json={"account_name": "John Doe", "merchant_tx_ref": "ORDER-2026-001"},
)
print(resp.json()["data"]["account_number"])
```

## Step 2: Fire a test payment

In test mode no real money moves, so use the simulator to send a `payment.received` webhook to your server:

```bash
curl -X POST https://api.nolubz.com/v1/simulate \
  -H "x-api-key: NDAPI-TEST-your_test_key" \
  -H "Content-Type: application/json" \
  -d '{
    "event": "payment.received",
    "webhook_url": "https://your-server.com/ndapi/webhook",
    "params": { "reference": "ORDER-2026-001", "amount": 10000 }
  }'
```

## Step 3: Handle the webhook

Verify the signature, then credit your customer with `net_amount`:

```javascript Node.js (Express)
const crypto = require("crypto");

app.post("/ndapi/webhook", express.raw({ type: "application/json" }), (req, res) => {
  const expected = crypto
    .createHmac("sha256", process.env.NDAPI_WEBHOOK_SECRET)
    .update(req.body) // raw bytes, exactly as received
    .digest("base64");

  const received = req.headers["x-ndapi-signature"] || "";
  if (expected.length !== received.length ||
      !crypto.timingSafeEqual(Buffer.from(expected), Buffer.from(received))) {
    return res.status(401).json({ error: "Invalid signature" });
  }

  const { event, data } = JSON.parse(req.body);
  if (event === "payment.received") {
    creditCustomer(data.reference, data.net_amount);
  }
  res.json({ received: true });
});
```
