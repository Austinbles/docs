This guide walks you through the five steps you need to go from a blank slate to a working NDAPI integration. By the end you will have authenticated successfully, queried your balance, created a virtual account, initiated a transfer, and set up webhook notifications. Every code example below uses the sandbox environment so you can experiment freely without touching live funds.

<Steps>

  ### Get your API key

  Before you can make any requests you need an API key. NDAPI uses Bearer token authentication — every request you send must include your key in the `Authorization` header.

  1. Sign up or log in at [https://dashboard.ndapi.io](https://dashboard.ndapi.io).
  2. Navigate to **Settings → API Keys**.
  3. Click **Create Key**, give it a descriptive name (for example, `my-app-sandbox`), and copy the key value immediately — it is only shown once.

  Test keys are prefixed with `ndapi_test_` and route all requests to the sandbox environment at `https://sandbox.ndapi.io/v1`. Use these for all development and testing. When you are ready to go live, create a live key (prefixed `ndapi_live_`) and switch your base URL to `https://api.ndapi.io/v1`.

  ### Make your first request

  The quickest way to verify your key is working is to query your account balance. Send a `GET` request to `/balance` with your key in the `Authorization` header.

  <CodeGroup>

  ```bash cURL
  curl --request GET \
    --url https://sandbox.ndapi.io/v1/balance \
    --header "Authorization: Bearer ndapi_test_YOUR_API_KEY" \
    --header "Content-Type: application/json"
  ```

  ```javascript Node.js
  const response = await fetch("https://sandbox.ndapi.io/v1/balance", {
    method: "GET",
    headers: {
      Authorization: "Bearer ndapi_test_YOUR_API_KEY",
      "Content-Type": "application/json",
    },
  });

  const data = await response.json();
  console.log(data);
  ```

  </CodeGroup>

  A successful response looks like this:

  ```json
  {
    "status": "success",
    "data": {
      "available": 150000.00,
      "ledger": 152500.00,
      "currency": "NGN"
    }
  }
  ```

  The `available` field reflects funds you can spend right now. The `ledger` balance includes pending transactions that have not yet settled.

  ### Create a virtual account

  Virtual accounts are dedicated bank account numbers you issue to your customers. When a customer pays into their virtual account, NDAPI matches the inbound payment to your reference automatically and fires a webhook event.

  <CodeGroup>

  ```bash cURL
  curl --request POST \
    --url https://sandbox.ndapi.io/v1/virtual-accounts \
    --header "Authorization: Bearer ndapi_test_YOUR_API_KEY" \
    --header "Content-Type: application/json" \
    --data '{
      "currency": "NGN",
      "customer_name": "Amara Okafor",
      "customer_email": "amara@example.com",
      "reference": "VA-001"
    }'
  ```

  ```javascript Node.js
  const response = await fetch("https://sandbox.ndapi.io/v1/virtual-accounts", {
    method: "POST",
    headers: {
      Authorization: "Bearer ndapi_test_YOUR_API_KEY",
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      currency: "NGN",
      customer_name: "Amara Okafor",
      customer_email: "amara@example.com",
      reference: "VA-001",
    }),
  });

  const data = await response.json();
  console.log(data);
  ```

  </CodeGroup>

  ```json
  {
    "status": "success",
    "data": {
      "id": "va_01HXYZ3K9QABCDE7FGHIJKLMN",
      "account_number": "9876543210",
      "bank_name": "NDAPI Payments Bank",
      "customer_name": "Amara Okafor",
      "customer_email": "amara@example.com",
      "currency": "NGN",
      "reference": "VA-001",
      "created_at": "2024-01-01T10:00:00Z"
    }
  }
  ```

  Share the `account_number` and `bank_name` with your customer. Any funds they send to that account are credited to your NDAPI balance and reconciled against the `reference` you provided.

  ### Initiate a transfer

  To send money to a bank account, post to `/transfers`. Always supply a unique `reference` for every transfer — NDAPI uses it to guarantee idempotency, so retrying the same reference never results in a duplicate payment.

  <CodeGroup>

  ```bash cURL
  curl --request POST \
    --url https://sandbox.ndapi.io/v1/transfers \
    --header "Authorization: Bearer ndapi_test_YOUR_API_KEY" \
    --header "Content-Type: application/json" \
    --data '{
      "amount": 5000,
      "currency": "NGN",
      "destination": {
        "account_number": "0123456789",
        "bank_code": "058",
        "account_name": "John Doe"
      },
      "narration": "Payment for services",
      "reference": "TRF-20240101-001"
    }'
  ```

  ```javascript Node.js
  const response = await fetch("https://sandbox.ndapi.io/v1/transfers", {
    method: "POST",
    headers: {
      Authorization: "Bearer ndapi_test_YOUR_API_KEY",
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      amount: 5000,
      currency: "NGN",
      destination: {
        account_number: "0123456789",
        bank_code: "058",
        account_name: "John Doe",
      },
      narration: "Payment for services",
      reference: "TRF-20240101-001",
    }),
  });

  const data = await response.json();
  console.log(data);
  ```

  </CodeGroup>

  ```json
  {
    "status": "success",
    "data": {
      "id": "trf_01HXYZ8M2PQRSTU9VWXYZABCD",
      "amount": 5000,
      "currency": "NGN",
      "destination": {
        "account_number": "0123456789",
        "bank_code": "058",
        "account_name": "John Doe"
      },
      "narration": "Payment for services",
      "reference": "TRF-20240101-001",
      "status": "pending",
      "created_at": "2024-01-01T10:05:00Z"
    }
  }
  ```

  The initial `status` is `pending`. NDAPI processes the transfer asynchronously and updates the status to `success` or `failed`. Subscribe to webhooks in the next step to receive that update in real time.

  ### Subscribe to webhooks

  Rather than polling the `/transfers/:id` endpoint to check whether a transfer settled, you can register a webhook URL and receive an HTTP `POST` notification the moment the status changes.

  Head to **Settings → Webhooks** in the [NDAPI dashboard](https://dashboard.ndapi.io) to register your endpoint URL, or use the `/webhooks` API to register programmatically. NDAPI will send a signed JSON payload to your URL for every event type you subscribe to — `transfer.success`, `transfer.failed`, `virtual_account.credit`, and more.

  For a full guide on verifying webhook signatures and handling events reliably, see the [Webhooks guide](/guides/handle-webhooks).

</Steps>
